# Eira 🌿

**Tu bienestar se construye día a día.**

Página web de Eira, una app de bienestar que reúne recetas saludables, rutinas de ejercicio y seguimiento de hábitos, pensada también para personas con resistencia a la insulina, diabetes o hipertensión.

## Qué incluye

- **Bienvenida interactiva** que recorre los pasos de la app.
- **Recetas** con filtros y detalle: tiempo, calorías, ingredientes, preparación y por qué es saludable.
- **Rutinas de ejercicio** con temporizador guiado y descansos automáticos.
- **Seguimiento de hábitos** (agua, sueño, actividad y ánimo) que se guarda en el navegador, con racha y gráfico semanal.
- **Página "Nosotros"** con el desafío, el equipo, la investigación y la solución.
- Modo claro y oscuro, diseño adaptable a celular y accesible con teclado.

## Tecnologías

HTML, CSS y JavaScript, sin frameworks ni librerías.
